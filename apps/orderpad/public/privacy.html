Privacy Policy

Orderpad is local-first. The orders you write up — the customer, the item, the size or option, the delivery address, whether they paid, whether it shipped and the ship-by date — are stored only in this browser (localStorage key orderpad:orders:v1). Language uses localStorage (orderpad:lang) and a td_lang cookie shared across try-dabble.com subdomains. Nothing is uploaded to our servers.

There is no Meta login. Orderpad does not connect to Instagram, WhatsApp, Facebook or any marketplace, does not read your messages, and does not ask for a social account. There are no accounts of any kind, no sign-in, no payment step, and no server-side copy of your order book. There is no order limit and no paid tier.

Export is local too. The JSON and CSV files are built inside this page and handed straight to your browser's download — they are never sent anywhere first. A JSON import is read in this page with the browser's own file reader; the file is not uploaded.

Because there is no server, there is no shared live view: two people cannot watch the same order book at once. It is one device, one pad.

Nothing expires on a timer. An order is removed only when you remove it, or when you clear site data in your browser.
